# public/models

Place the perfume bottle 3D model here as:

```
public/models/perfume-bottle.glb
```

Download it manually (this project does not fetch it automatically):
https://pixabay.com/3d-models/glb-perfume-bottle-glass-vial-4060/

If the file is missing, the site automatically renders a hand-built CSS
fallback bottle instead — no white screen, no crash. In development mode a
small notice is logged to the console (and shown in a corner badge) when the
fallback is active.
